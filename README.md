# Multimodal Construction Intelligence Platform
Skill Wallet Capstone Project 1 — Streamlit + Google Gemini.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Deploy on Streamlit Community Cloud
1. Push `app.py`, `requirements.txt`, `README.md` to a GitHub repo.
2. share.streamlit.io -> New app -> select repo, main file `app.py`.
3. (Optional) App settings -> Secrets: `GEMINI_API_KEY = "your-key"`.
   Otherwise users paste a key in the sidebar; with no key the app runs in demo mode.

## Modules
Safety & PPE audit · Crack diagnostics · Planning & valuation · Daily assistant + weather advisory
